# Torti Spawn Catalog Rework

Rework of the MM2 Torti Hub spawn menu.

What changed:
- Added an `Open Catalog` button in the `Spawner` tab
- Catalog opens in a separate glass-style window
- Item cards use the layout: image, name, currency, `Spawn`
- Secondary text is now gray for a cleaner dark theme
- The catalog uses a full `Close` button instead of a minimize-style control

Main script:
- `main.lua`

Alternative loader for the protected entry:
- `key-loader.lua`

Split loader:
- `main-split-loader.lua`
